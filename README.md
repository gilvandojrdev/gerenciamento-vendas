# Gerenciamento de vendas

Um sistema responsável por gerenciar as vendas de uma determinada loja, permitindo o cadastro de customers com informações pessoais, como:

- Nome
- Idade
- Saldo na loja
- Salário

Além disso, futuramente o sistema também armazenará informações financeiras relacionadas à loja, como:

- Valores pendentes
- Valores pagos
- Identificação do customer por ID (numeração única)

Arquitetura do projeto:

- Salvamento de customers por mémoria.
- Injeção de Dependência e Programação voltada a Interfaces para garantir o baixo acoplamento.
